# 👾 ITCH.AI

**The AI you didn't ask for, but unfortunately cannot get rid of.**

ITCH.AI is an AI-powered entertainment experience that turns ordinary conversations into chaotic, hilarious interactions. Unlike your usual polite assistant, ITCH.AI is sarcastic, sassy, unpredictable and always ready to argue.

Featuring a cinematic, terminal-style interface, dynamic roasts, ridiculous challenges and a hilarious BLOCK IT feature that brings the AI back under a new identity.

## 🎯 Theme
**SUPER UNINTELLIGENCE AI**

## ✨ Features
- Gemini-powered dynamic conversations.
- Sassy, sarcastic and context-aware personality.
- Music-video-style sequential text animations.
- Unexpected challenges and interactive tasks.
- BLOCK IT feature with a fictional AI comeback.
- Conversation history and image uploads.
